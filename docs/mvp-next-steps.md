# StyleMate 下一步任务清单

## 当前状态

"穿"与"买"两条闭环已基本成型：

- **穿**：风格测评 → 衣橱录入 → 今天穿什么（含空衣橱起步方案）→ 周计划 → 诊断 + 衣橱替换建议 → 帮我搭这件。
- **买**：衣橱缺口分析（AI 个性化）→ 购物清单（勾选/预算/优先级）→ 值得买吗（空衣橱可用）。
- **留存**：诊断历史（最近 5 次）、报告分享图、登录后数据跨设备同步。

## P0：建议立即做

### 1. 周计划与风格档案服务端同步

目标：换设备后计划不丢。

- 把 `stylemate.plan`（周计划）与 `stylemate.styleProfile.v1`（风格档案）在登录后同步到服务端。
- 登录后拉取合并，登出后保留本机副本。

### 2. 电商导购链接

目标：把"该买什么"变成"一键去买"。

- 购物清单/值得买结果/起步方案接入商品搜索链接（淘宝联盟/京东联盟）。
- 缺口分析给出对应品类的商品推荐位。
