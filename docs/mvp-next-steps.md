# StyleMate 下一步任务清单

## 当前状态

"穿"与"买"两条闭环已基本成型：

- **穿**：风格测评 → 衣橱录入 → 今天穿什么（含空衣橱起步方案）→ 周计划 → 诊断 + 衣橱替换建议 → 帮我搭这件。
- **买**：衣橱缺口分析（AI 个性化）→ 购物清单（勾选/预算/优先级）→ 值得买吗（空衣橱可用）。

## 已完成（历史清单归档）

- [x] 图片上传大小限制（8MB，前后端校验）。
- [x] 本地风格档案清除/重新生成。
- [x] AI 错误提示与重试优化。
- [x] 衣橱前端接入：AI 拍照识别、手动录入、分类/子类筛选、单品详情。
- [x] 今天穿什么：天气 + 衣橱 + 记忆混合评分推荐。
- [x] 空衣橱起步方案：不再报错，给出建议购买单品 + 预算。
- [x] 帮我搭这件：单品出发的 3 套搭配。
- [x] 周穿搭计划：方案排期、标记已穿、手动换单品。

- [x] 购物清单：CRUD、勾选已买、优先级、预算合计、自动去重。
- [x] 值得买升级：空衣橱可用、建议搭配方案。
- [x] 登录注册（JWT）。

## P0：建议立即做

### 1. 诊断历史与报告分享图

目标：提升留存与传播。

- 诊断成功后本地保存最近 5 次（沿用 localStorage）。
- 风格档案/诊断结果生成分享卡片（核心风格、分数、关键词、品牌标识）。

### 2. 登录态与用户数据全链路打通

目标：跨设备同步，用户敢投入录入衣橱。

- 衣橱/推荐/购物清单目前用本地 userId，登录后应切换到服务端 userId。
- 登录后把本地数据（衣橱、计划、购物清单）合并到账号。
- 全部私有接口强制 JWT 鉴权 + 资源归属校验。

## P1：短期做

### 3. 电商导购链接

目标：把"该买什么"变成"一键去买"。

- 购物清单/值得买结果/起步方案接入商品搜索链接（淘宝联盟/京东联盟）。
- 缺口分析给出对应品类的商品推荐位。

### 4. 社区 OOTD

目标：验证社交传播。

- 诊断结果一键发布 OOTD（图片 + 评分 + 文案）。
- 点赞、收藏、评论。

## P2：后续做

- 会员订阅与 AI 额度。
- 虚拟试穿（接入试穿模型）。
- 小程序 / App。

## 不建议马上做

- 完整电商平台自营（供应链重）。
- 更多风格库内容扩充（当前 80 种已足够）。
