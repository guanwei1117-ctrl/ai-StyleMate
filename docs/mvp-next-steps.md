# StyleMate 下一步任务清单

## 当前状态

"穿"与"买"两条闭环已基本成型：

- **穿**：风格测评 → 衣橱录入 → 今天穿什么（含空衣橱起步方案）→ 周计划 → 诊断 + 衣橱替换建议 → 帮我搭这件。
- **买**：衣橱缺口分析（AI 个性化）→ 购物清单（勾选/预算/优先级）→ 值得买吗（空衣橱可用）。
- **留存**：诊断历史（最近 5 次）、报告分享图、登录后数据跨设备同步。

## P0：建议立即做

### 1. 淘宝客联盟接入（Provider 已就绪，只差 Key）

目标：从"搜索深链"升级为"真实商品卡 + 佣金链接"。

- 注册淘宝联盟账号，申请 AppKey/AppSecret/推广位 adzone_id，填入 `.env` 的 `TAOBAO_APP_KEY / TAOBAO_APP_SECRET / TAOBAO_ADZONE_ID` 即可自动启用，无需改代码。
- 前端展示商品卡（图/价/券），点击跳转佣金链接；接口调用失败自动回退深链。
- 合规：页面标注"推广/返利"说明。

目标：让社区能自运转。

- 我的帖子列表与个人主页。
- 分享卡直出文案优化（诊断摘要自动填充）。
