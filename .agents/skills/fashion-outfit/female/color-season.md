 # 女性四季色彩理论
 
 ## 四季色彩基础
 
 四季色彩理论根据肤色、发色、瞳色的冷暖调与明暗度，将人分为四个季型。
 不同季型适合不同的颜色体系。
 
 ## 1. 春季型（Warm + Light）
 
 **特征**：
 - 肤色：暖调、浅淡、透亮（象牙白/浅杏色/桃粉色底）
 - 发色：浅棕/栗色/金色/红棕（偏暖）
 - 瞳色：浅棕/琥珀/浅绿/浅蓝
 
 **适合色系**：暖调、明快、清澈的颜色
 
 | ✅ 推荐 | ❌ 避开 |
 |---------|---------|
 | 珊瑚粉、桃色、橘色 | 深黑色（太沉重） |
 | 薄荷绿、浅草绿 | 冷紫色、深紫 |
 | 鹅黄色、奶油白 | 酒红、棕褐色 |
 | 浅蓝、天蓝 | 灰褐色、暗色调 |
 | 驼色、浅棕 | 荧光色（太刺眼） |
 
 **核心配色**：薄荷绿+奶油白 / 珊瑚粉+米色 / 鹅黄+浅蓝
 
 ## 2. 夏季型（Cool + Light）
 
 **特征**：
 - 肤色：冷调、偏粉、玫瑰底（粉白/冷白/玫瑰米色）
 - 发色：灰棕/亚麻/深棕带灰/黑（偏冷）
 - 瞳色：灰蓝/灰绿/深棕/黑
 
 **适合色系**：冷调、柔和、雾感的颜色
 
 | ✅ 推荐 | ❌ 避开 |
 |---------|---------|
 | 雾霾蓝、灰蓝 | 荧光色（亮橙/亮黄/亮粉） |
 | 灰粉色、玫瑰粉 | 纯黑色（可用深灰替代） |
 | 淡紫色、薰衣草紫 | 纯橙色、暖调橙红 |
 | 乳白色、米灰色 | 金色的(配饰选银色) |
 | 淡灰、银灰 | |
 
 **核心配色**：雾霾蓝+灰 / 灰粉+米灰 / 薰衣草紫+白
 
 ## 3. 秋季型（Warm + Dark）
 
 **特征**：
 - 肤色：暖调、偏黄、金色底（暖黄皮/金色调/橄榄色调）
 - 发色：深棕/红棕/铜色/黑（暖调）
 - 瞳色：棕/深棕/琥珀/绿
 
 **适合色系**：暖调、浓郁、大地感的颜色
 
 | ✅ 推荐 | ❌ 避开 |
 |---------|---------|
 | 橄榄绿、苔藓绿 | 粉色（所有粉色调） |
 | 锈红色、砖红 | 亮蓝色 |
 | 驼色、卡其、咖啡 | 银色(配饰选金色) |
 | 芥末黄、姜黄 | 冷紫色 |
 | 深棕、巧克力色 | 黑色（可用深棕替代） |
 | 酒红、勃艮第红 | |
 
 **核心配色**：驼色+橄榄绿+锈红 / 卡其+棕+芥末黄 / 酒红+深棕+米
 
 ## 4. 冬季型（Cool + Dark）
 
 **特征**：
 - 肤色：冷调、偏粉或偏青（冷白皮/青调/玫瑰调）
 - 发色：黑/深棕带灰蓝/银白（冷调）
 - 瞳色：深棕/黑/灰蓝
 
 **适合色系**：冷调、高对比、饱和的颜色
 
 | ✅ 推荐 | ❌ 避开 |
 |---------|---------|
 | 纯黑、纯白 | 大地色系（驼/卡其/棕） |
 | 正红、宝蓝 | 柔和粉彩（马卡龙色） |
 | 翠绿、翡翠绿 | 暖调橙色/黄色 |
 | 冷紫、紫罗兰 | 浊色/浑浊色调 |
 | 灰色、银灰 | |
 | 深蓝、藏蓝 | |
 
 **核心配色**：黑+白+红 / 藏蓝+银灰+冷紫 / 翠绿+黑+白
 
 ## 5. 如何判断自己的季型
 
 ### 快速自测法
 
 **Step 1: 判断冷暖调**
 ```
 看手腕血管颜色：
 - 绿色/橄榄色 → 暖调（春/秋）
 - 蓝色/紫色 → 冷调（夏/冬）
 
 或者：戴金色vs银色首饰
 - 金色显气色 → 暖调
 - 银色显气色 → 冷调
 ```
 
 **Step 2: 判断明暗度**
 ```
 - 浅发色/浅瞳色/皮肤透亮 → 浅调（春/夏）
 - 深发色/深瞳色/对比度高 → 深调（秋/冬）
 ```
 
 **Step 3: 综合判断**
 - 暖调+浅 → **春季型**
 - 冷调+浅 → **夏季型**
 - 暖调+深 → **秋季型**
 - 冷调+深 → **冬季型**
 
 ## 6. 四季色彩穿搭建议
 
 | 季型 | 最佳中性色 | 最佳点缀色 | 最佳金属配饰 | 最佳口红 |
 |------|-----------|-----------|------------|---------|
 | 春季 | 奶油白/驼/浅灰 | 珊瑚/薄荷/鹅黄 | 金色 | 珊瑚粉/西柚色 |
 | 夏季 | 米灰/乳白/灰蓝 | 雾蓝/灰粉/淡紫 | 银色/白金 | 豆沙粉/玫瑰豆沙 |
 | 秋季 | 卡其/驼/橄榄 | 锈红/芥末/酒红 | 金色/古铜 | 砖红/南瓜色 |
 | 冬季 | 黑/白/藏蓝/灰 | 正红/宝蓝/翠绿 | 银色/白金 | 正红/梅子色 |
 
 ## 7. 注意事项
 
 - 四季色彩是**参考框架**而非铁律，可以根据个人喜好灵活运用
 - 亚洲人常见：暖黄皮居多，秋季型与春季型较多
 - 如果肤色介于两个季型之间，可以取两个季型颜色的交集
 - 最重要的不是"你属于哪一季"，而是"什么颜色让你看起来气色好"
 - 可以用10%点缀色来尝试不属于自己季型的颜色，降低风险
