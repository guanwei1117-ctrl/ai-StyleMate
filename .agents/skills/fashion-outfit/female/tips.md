 # 女性穿搭技巧合集
 
 ## 1. 法式基础法则（Parisian Chic）
 
 - **1个亮点单品**：丝巾/红唇/项链/贝雷帽 — 选1个，其他全基础款
 - **牛仔裤+白衬衫+芭蕾鞋** = 法式入门
 - **不完美=有味道**：不过度打扮，衬衫皱一点、头发松一点更有魅力
 - **露肤克制**：最多露1处（领口或腿或手腕，不叠加）
 - **配饰**：细项链、丝巾、藤编包、芭蕾鞋
 - **色彩**：中性色 + 红/蓝/条纹
 
 ## 2. 韩系穿搭法则（K-Fashion）
 
 - **Overlay（叠穿）**：T恤+衬衫+针织+外套 — 层次是灵魂
 - **宽松但不臃肿**：Oversize配修身下装，上宽下窄
 - **柔和色调**：奶白/燕麦/灰/蓝/粉/浅紫
 - **配饰**：发夹、细项链、棒球帽、帆布包、厚底鞋
 - **裤型**：阔腿裤/直筒裤/微喇裤
 - **裙型**：A字迷你裙/长百褶裙
 
 ## 3. 显高法则（<160cm）
 
 - **腰线=命线**：永远高腰，腰带强化
 - **鞋裤同色**：视觉延伸腿部
 - **V领**：延长颈部视觉
 - **裙长严格**：膝上≈大腿中，或踝上5-10cm；❌ 卡在小腿肚
 - **外套长度**：短<臀部或长>膝盖，❌ 卡在臀部最宽处
 - **裤长**：九分露脚踝，或鞋裤同色延伸
 - **尖头鞋**：增加腿长视觉
 - **上下同色**：纵向统一，不分段
 
 ## 4. 显瘦视觉欺骗
 
 | 技巧 | 原理 |
 |------|------|
 | 竖条纹/纵向缝线 | 拉长视觉 |
 | 深色在你想显瘦的部位 | 收缩色原理 |
 | 露你最瘦的部位（锁骨/手腕/脚踝） | 聚焦优势 |
 | V领 | 露出锁骨+延长颈部 |
 | 垂感面料 | 纵向线条，不蓬不膨胀 |
 | 腰线越高越显瘦 | 比例优化 |
 | 竖向拉链/纽扣线 | 视觉竖直线 |
 | 长项链 | V形纵向线 |
 
 ## 5. 女性百搭色库
 
 ### 女士万能色（任意搭配不出错）
 米色、燕麦、奶油、灰粉、藏蓝、酒红、豆沙色、雾霾蓝、橄榄绿、驼色、奶白
 
 ### 亚洲人友好色（暖黄皮适用）
 豆沙粉 > 芭比粉（避开荧光芭比粉）
 雾霾蓝 > 宝蓝
 橄榄绿 > 翠绿
 驼色 > 纯橙
 酒红 > 正红
 奶白 > 纯白
 
 ## 6. 裙长公式
 
 | 裙长 | 效果 | 适合场景 | 适合身高 |
 |------|------|---------|---------|
 | Mini（大腿中） | 活泼、年轻、显腿长 | 约会/日常/派对 | 所有身高 |
 | Midi（膝下-踝上） | 优雅、知性、得体 | 通勤/约会/商务 | >160cm更佳 |
 | Maxi（及踝/及地） | 浪漫、慵懒、气场 | 约会/度假 | >160cm更佳 |
 
 **⚠️ 雷区**：裙摆卡在小腿肚 → 显腿短腿粗，❌
 
 ### 裙型推荐
 - **A字裙**：所有体型通用，遮臀遮腿
 - **铅笔裙**：沙漏型/梨型（偏瘦）
 - **百褶裙**：H型/偏瘦（增加体积）
 - **伞裙**：梨型遮胯，X型突出腰
 - **直筒裙**：H型/高个子
 
 ## 7. 鞋款与裤长匹配
 
 | 鞋型 | 最佳裤型 | 效果 |
 |------|---------|------|
 | 尖头高跟鞋 | 阔腿裤/西裤 | 延伸腿长，优雅 |
 | 尖头平底鞋 | 九分裤/裙子 | 舒适+延伸 |
 | 小白鞋 | 直筒裤/牛仔裤 | 休闲百搭 |
 | 乐福鞋 | 九分裤/卡其裤 | 学院感 |
 | 玛丽珍 | 裙子/直筒裤 | 复古少女 |
 | 芭蕾鞋 | 裙子/九分裤 | 法式随意 |
 | 马丁靴 | 窄脚裤/短裙 | 硬朗+甜酷 |
 | 切尔西靴 | 直筒裤/紧身裤 | 秋冬百搭 |
 | 厚底鞋 | 阔腿裤/长裙 | 显高+休闲 |
 
 **核心**：露脚背 = 延伸腿长；鞋面有横带 = 截断腿长（慎用）
 
 ## 8. 女性穿搭常见雷区
 
 | ❌ 不要 | ✅ 替代 |
 |---------|--------|
 | 全身上下都宽松 | 上宽下窄/上窄下宽 |
 | 全身都紧身 | 松紧搭配有节奏 |
 | 低腰裤（非Y2K风格） | 高腰裤 |
 | 中长裙卡小腿肚 | 膝上或踝上 |
 | 裙+裤叠穿不协调 | 统一色系避免截断 |
 | Leggings当裤子穿（外穿） | 配长上衣/裙/短裤 |
 | 艳色全身 | 中性色+1亮色 |
 | 上下都花 | 1花+1纯色 |
 | 内衣外露（非设计款） | 选择合适的内衣/无痕 |
 | 包和鞋颜色多且不协调 | 包鞋同色或中性色 |
 
 ## 9. 女性各季节穿搭
 
 ### 春夏
 - 颜色：浅色/粉彩/亮色点缀
 - 材质：棉/麻/真丝/雪纺/薄针织
 - 露肤：锁骨/手臂/脚踝/腿 — 选1-2处
 - 鞋：凉鞋/单鞋/芭蕾鞋/小白鞋
 - 外套：薄西装/牛仔夹克/针织开衫/Bomber
 
 ### 秋冬
 - 颜色：深色/暖色/大地色/酒红/墨绿/驼色
 - 材质：羊毛/羊绒/灯芯绒/呢料/皮/针织
 - 层次：3层+，利用围巾/帽子增加氛围
 - 鞋：靴子（马丁/切尔西/长靴）
 - 外套：大衣/羽绒/皮草/毛呢
 
 ## 10. 女性快速穿搭公式
 
 ### 5分钟日常
 白T + 直筒牛/阔腿裤 + 小白鞋 + 任意外套
 
 ### 10分钟通勤
 针织衫 + A字裙/西裤 + 乐福鞋/尖头鞋 + 大衣/Blazer
 
 ### 15分钟约会
 丝质/修身连衣裙 + 踝靴/玛丽珍 + 细项链
 或 修身针织 + 阔腿裤 + 尖头高跟鞋
 
 ### 20分钟正式
 衬衫 + 铅笔裙 + 西装外套 + 中跟鞋 + 简约首饰
