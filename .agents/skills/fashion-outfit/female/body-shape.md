 # 女性体型适配
 
 ## 女性五大体型诊断
 
 ### 梨型 / A型（亚洲女性最常见）
 
 **特征**：胯宽 > 肩宽，臀部/大腿有肉，上半身偏瘦
 
 **原则**：弱化下半身，强调上半身，制造视觉平衡
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 宽肩设计：泡泡袖/一字领/肩章 — 加宽肩部平衡胯宽 | 紧身包臀裙/裤 — 暴露胯宽 |
 | A字裙/阔腿裤/伞裙 — 遮胯遮大腿 | 浅色下装 — 膨胀下半身 |
 | 上浅下深/上花下素 — 把注意力引到上半身 | 大口袋/装饰在胯部 |
 | V领/U领 — 延长颈线 | 横条纹在臀胯部 |
 | 收腰X型连衣裙 — 突出腰线 | 太贴身的针织裙/弹力面料 |
 | 修身/紧身上衣 — 展示上半身优势 | 裤脚太紧（窄脚裤） |
 | 垫肩Blazer — 加宽肩部 | |
 
 **代表人物**：Beyoncé、Jennifer Lopez
 
 ### 苹果型 / O型
 
 **特征**：腰粗/腹部突出，四肢偏细，胸围较大
 
 **原则**：制造纵向线条，转移注意力到四肢
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | V领/U领 — 延长颈部，聚焦锁骨 | 紧身腰/腰部有装饰 — 凸显肚子 |
 | 垂感面料 — 纵向拉长 | 横条纹 — 横向加宽 |
 | 高腰A字连衣裙 — 遮腹不勒腰 | 中高腰紧身裤 — 勒出肚子 |
 | 外套敞开穿 — V形纵向线条 | 高领/小圆领 — 显得上半身满 |
 | 聚焦腿部 — 短裙/露腿 | 扎腰/塞衣角 — 暴露腰腹 |
 | 帝国腰（胸下收腰）连衣裙 | 亮色/浅色在腹部 |
 
 **代表人物**：Queen Latifah、Adele(早期)
 
 ### 沙漏型 / X型
 
 **特征**：肩宽≈胯宽，腰细（最女性化的体型）
 
 **原则**：突出腰线，不要隐藏你的曲线
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 收腰款/腰封/腰带 — 强调细腰 | 宽松直筒/H型 — 埋没曲线 |
 | 包裹型连衣裙（Bodycon） — 展示曲线 | 太过宽松的上衣或外套 |
 | V领+包臀 — 绝杀组合 | 无腰线的大码外套 |
 | X型外套（收腰设计） | 肩部过宽的设计（泡泡袖过量） |
 | 铅笔裙/包臀裙 | |
 
 **代表人物**：Scarlett Johansson、Marilyn Monroe
 
 ### 矩形 / H型
 
 **特征**：肩≈腰≈胯，无明显曲线，偏瘦
 
 **原则**：制造曲线，增加体积感
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 腰封/腰带 — 制造人工腰线 | 直筒连衣裙 — 直上直下 |
 | 上V+下A（V领上衣+A字裙） — 制造X | 太过中性/方正的单品 |
 | 荷叶边/褶皱/层次 — 增加体积 | 垂感太强的贴身面料 |
 | 泡泡袖/宽肩+阔腿裤 — 制造沙漏错觉 | |
 | 横条纹/印花 — 增加宽度感 | |
 | 收腰款 | |
 
 **代表人物**：Keira Knightley、周迅
 
 ### 草莓型 / V型 / 倒三角
 
 **特征**：肩宽 > 胯宽，上半身较壮，下半身纤细
 
 **原则**：弱化肩部，强调下半身
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | V领/U领 — 切断肩宽视觉 | 垫肩/泡泡袖/肩章 — 加宽肩部 |
 | 阔腿裤/A字裙/喇叭裤 — 加大下半身 | 窄脚裤/紧身裙 — 上下对比强烈 |
 | 上深下浅 — 深色收缩肩，浅色扩张臀 | 横条纹/大图案在上半身 |
 | 插肩袖/落肩款 — 不强调肩线 | 发泡袖/羊腿袖 |
 | 垂感面料在上半身 | 一字领/船型领 |
 
 **代表人物**：Cate Blanchett、Angelina Jolie
 
 ## 女性体型快速判断表
 
 | 观察点 | 梨型(A) | 苹果(O) | 沙漏(X) | 矩形(H) | 草莓(V) |
 |--------|--------|---------|---------|---------|---------|
 | 肩vs胯 | 肩<胯 | 肩≈胯 | 肩≈胯 | 肩≈胯 | 肩>胯 |
 | 腰线 | 有 | 无(粗) | 明显细 | 无 | 有 |
 | 肉分布 | 下半身 | 腹部 | 均匀 | 均匀偏瘦 | 上半身 |
 | 最佳裙型 | A字 | 垂感/帝国腰 | 包裹/收腰 | 有结构/A字 | A字/阔腿 |
 | 最佳领型 | 宽领/一字领 | V领/U领 | V领/各种 | V领/各种 | V领/U领 |
 | ❌ 禁忌 | 紧身下装 | 勒腰 | H型直筒 | 直筒/无腰 | 强调肩宽 |

 | 体型 | 最适合风格 | 第二适合 |
