 # 女装风格指南
 
 ## 1. 法式 / Parisian
 
 **关键词**：Effortless Chic、基础款+1亮点、不经意的精致
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 牛仔裤（直筒/微喇）、白衬衫、条纹衫、针织开衫、丝质连衣裙、风衣 |
 | 配色 | 中性色(白/黑/米/卡其/灰) + 红/蓝/条纹 |
 | 配饰 | 丝巾(red flag)、藤编包、细项链、芭蕾鞋、贝雷帽 |
 | 公式 | 白衬衫+蓝牛+芭蕾鞋+红唇 |
 
 ## 2. 韩系 / K-Fashion
 
 **关键词**：叠穿、宽松柔和、温柔色、少女感/高级感并存
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 长大衣、阔腿裤、针织开衫、百褶裙、卫衣、帆布包 |
 | 配色 | 燕麦/米/灰/雾蓝/粉/浅紫/奶白 — 柔和低饱和 |
 | 配饰 | 发夹、细项链、棒球帽、厚底鞋、帆布包 |
 | 公式 | 针织开衫+吊带+阔腿裤+运动鞋 |
 
 ## 3. 日系 / J-Fashion
 
 **关键词**：层次感、自然面料、松弛、大地色
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 棉麻衬衫、宽裤/阔腿裤、帆布鞋、针织衫、工装、风衣 |
 | 配色 | 大地色(驼/棕/卡其/橄榄/灰)+中性色 |
 | 配饰 | 帆布包、草帽、手表、手帕 |
 | 公式 | 棉麻衬衫+宽裤+帆布鞋+帆布包 |
 
 ## 4. 欧美 / Minimal Western
 
 **关键词**：简约、力量感、大女人、轮廓分明
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | Blazer、西裤、直筒牛仔裤、白T、针织、高跟鞋 |
 | 配色 | 黑+白+灰+藏蓝+红 — 干净利落 |
 | 配饰 | 金色饰品、手表、简约包、墨镜 |
 | 公式 | Blazer+白T+直筒裤+高跟鞋 |
 
 ## 5. 极简 / Minimal
 
 **关键词**：少即是多、无Logo、质感、中性色
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 高品质T恤、羊毛大衣、真丝衬衫、羊绒针织、直筒/阔腿裤 |
 | 配色 | 黑/白/灰/驼/藏蓝 — 全中性色，无图案 |
 | 材质 | 羊绒、真丝、羊毛、高品质棉 — 质感第1 |
 | 配饰 | 几乎没有，最多1件金属饰品 |
 | 公式 | 真丝衬衫+羊毛阔腿裤+尖头鞋 |
 
 ## 6. 波西米亚 / Boho
 
 **关键词**：自由、浪漫、碎花、流苏、编织
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 碎花连衣裙、流苏外套、阔腿裤、钩针上衣、宽檐帽 |
 | 配色 | 暖色+大地色(锈红/芥末/驼/橄榄/酒红) |
 | 材质 | 棉麻、钩针、蕾丝、麂皮、流苏 |
 | 配饰 | 宽檐帽、多层项链、流苏包、编织腰带 |
 | 公式 | 碎花裙+宽檐帽+编织包+流苏凉鞋 |
 
 ## 7. Old Money / Quiet Luxury
 
 **关键词**：经典、质感、克制、无Logo、好面料
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 羊绒衫、丝质衬衫、花呢外套、A字裙、乐福鞋、风衣 |
 | 配色 | 中性色+深蓝+米+灰 — 无鲜艳色 |
 | 材质 | 羊绒、真丝、花呢、羊毛 — 一眼贵 |
 | 配饰 | 珍珠、金表、真皮包 — 简约而精致 |
 | 公式 | 羊绒针织+A字裙+乐福鞋+金表 |
 
 ## 8. Y2K / 千禧风
 
 **关键词**：低腰、短上衣、亮色、个性、叛逆
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | Crop Top、低腰裤、微喇牛仔裤、短裙、工装裤 |
 | 配色 | 亮色+金属色+黑/粉/蓝 |
 | 配饰 | 细腰带、蝴蝶发夹、墨镜、迷你包 |
 | 公式 | Crop Top+低腰微喇+厚底鞋 |

 ## 10. 风格进阶路径
 
 ```
 Level 1: 法式/韩系 → 建立基础审美（3-6个月）
 Level 2: 日系/极简 → 探索质感/层次（6-12个月）
 Level 3: Old Money/欧美 → 建立高级感（1-2年）
 Level 4: 多风格混搭 → 个人风格成熟（2年+）
 ```
