 # 男装风格指南
 
 ## 1. Clean Fit（当前最🔥）
 
 **关键词**：合身、干净、质感、基础款
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 白T、直筒牛仔裤、小白鞋、针织衫、Harrington夹克 |
 | 配色 | 中性色+1个点缀色，全身不超过3色 |
 | 版型 | 合身(Slim Straight/Regular Fit) 不紧不松 |
 | 材质 | 棉、羊毛、牛仔、帆布 — 自然质感 |
 | 配饰 | 克制 — 1块手表/1个包足矣 |
 | 代表人物 | @kenijima、周杰伦(近期)、王一博(日常) |
 | 公式 | 白T+直筒牛+白鞋+任意外套 |
 
 ## 2. Ivy / Preppy 学院风
 
 **关键词**：经典、学院、知识分子、美国东海岸
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | Blazer、卡其裤、乐福鞋、牛津衬衫、V领毛衣、领带 |
 | 配色 | 藏蓝/卡其/白/灰/酒红/绿 |
 | 版型 | 合身偏宽松，不紧绷 |
 | 材质 | 羊毛、棉、帆布 |
 | 配饰 | 领带、帆布腰带、编织皮带、帆布包 |
 | 公式 | 牛津衬衫+V领毛衣+卡其裤+乐福鞋 |
 
 ## 3. Gorpcore / Urban Outdoor
 
 **关键词**：机能、户外、工装、城市+自然
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 冲锋衣/软壳、工装裤、登山鞋/溯溪鞋、抓绒、机能马甲 |
 | 配色 | 军绿/黑/橘/蓝/大地色 |
 | 版型 | 宽松，便于活动 |
 | 材质 | 科技面料(Gore-Tex)、尼龙、抓绒、CORDURA |
 | 配饰 | 渔夫帽/棒球帽、机能包、登山扣、手套 |
 | 公式 | 冲锋衣+工装裤+登山鞋 |
 
 ## 4. Minimal / 极简
 
 **关键词**：少即是多、无Logo、质感、黑白灰
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 优质T恤、羊毛大衣、直筒西裤、切尔西靴、羊绒衫 |
 | 配色 | 黑/白/灰/驼/藏蓝 — 全无彩色 |
 | 版型 | 修身到标准，垂感好 |
 | 材质 | 羊绒、羊毛、真丝、高品质棉 |
 | 配饰 | 几乎没有，最多一块简约手表 |
 | 公    式 | 全黑/全灰 + 不同材质层次 |
 
 ## 5. Vintage / 复古 / Americana
 
 **关键词**：二手感、靛蓝、暖调、经典工艺
 
 | 维度 | 说明 |
 |------|------|
 | 核心单品 | 原色牛、帆布鞋、工装夹克、军装、复古T、皮靴 |
 | 配色 | 靛蓝/卡其/棕/橄榄/酒红 |
 | 版型 | 宽松偏落肩，还原时代剪裁 |
 | 材质 | 原色丹宁、帆布、皮革、厚棉 |
 | 配饰 | 皮带、帆布包、报童帽 |
 | 公式 | 原色牛+白T+帆布鞋+工装夹克 |

 ## 10. 风格混搭建议
 
 | 混搭组合 | 效果 | 推荐人群 |
 |---------|------|---------|
 | Clean Fit + Ivy | 精致日常 | 通勤族 |
 | Workwear + Vintage | 粗犷复古 | 爱好复古的人 |
 | Minimal + Gorpcore | 城市机能 | 都市户外人 |
 | Dark Academia + Clean Fit | 书卷气日常 | 文艺青年 |
 | Varsity + Clean Fit | 活力日常 | 年轻人 |
 
 ## 11. 初学者风格推荐路径
 
 ```
 Level 1: Clean Fit → 建立基础衣橱（3个月）
 Level 2: Clean Fit + Ivy → 探索色彩/层次（6个月）
 Level 3: Clean Fit + 目标风格 → 形成个人风格（1年）
 Level 4: 多风格混搭 → 建立完整审美体系（2年+）
 ```
