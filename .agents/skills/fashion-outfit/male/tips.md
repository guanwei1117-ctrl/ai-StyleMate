 # 男性穿搭技巧合集
 
 ## 1. Clean Fit 核心哲学
 
 - **合身但不紧身**：衣服贴合身体轮廓，但不过分紧绷
 - **颜色不超过3种**：极简配色是男性穿搭第一原则
 - **少即是多**：宁简勿繁，配饰克制的男人更有品
 - **质感 > 设计**：好面料 > 花哨设计
 
 ## 2. 男性必备单品库（胶囊衣橱）
 
 ### 上装
 - 白T（3件不同磅数：薄/中/厚）
 - 牛津衬衫（蓝/白各1件）
 - 针织衫（灰/黑/藏蓝）
 - 条纹海魂衫（法式休闲必备）
 - 亨利衫（替代T恤的进阶选择）
 
 ### 下装
 - 直筒牛仔裤（原色/浅蓝）
 - 卡其裤/Chinos（卡其/军绿/藏蓝/灰）
 - 深色西裤（商务/正式）
 - 白色长裤（春夏休闲）
 - 短裤（不过膝，简洁款）
 
 ### 外套
 - 牛仔夹克（经典蓝/黑）
 - Harrington夹克/A-1（春日百搭）
 - Blazer/休闲西装（海军蓝）
 - Mac Coat/Trench Coat（过渡季节）
 - 羽绒/派克大衣（冬季）
 - 皮质夹克（个性升级）
 - 工装夹克（实用+户外）
 
 ### 鞋履
 - 白色板鞋（万能搭配，推荐Common Projects/Axel Arigato风格）
 - 乐福鞋/德比鞋（商务休闲）
 - 切尔西靴（秋冬百搭）
 - 帆布鞋/Converse（休闲）
 - 沙漠靴/Dessert Boot（百搭秋冬）
 - 运动鞋（一双好质感复古跑鞋就够了）
 
 ### 配饰
 - 手表（钢带/皮带各1块）
 - 皮质背包/帆布托特包
 - 腰带（与鞋同色）
 - 围巾（中性色/格纹）
 - 墨镜（经典飞行员/Wayfarer）
 - 包：帆布托特 > 双肩包 > 斜挎包
 
 ## 3. 男装配色安全区
 
 ### 万能配色公式
 - 藏蓝上装 + 卡其下装 + 白鞋 = 最安全
 - 白T + 蓝牛 + 白鞋 = 经典永不过时
 - 灰上装 + 黑下装 + 黑鞋 = 极简高级
 - 白上装 + 卡其下装 + 棕鞋 = 清爽温暖
 - 黑上装 + 蓝牛 + 黑鞋 = 日常硬朗
 
 ### 男士三宝色（任意组合不出错）
 **藏蓝 / 卡其 / 白色**
 
 ### 全黑搭配原则
 - 不同材质的黑（棉/牛仔/皮/羊毛）制造层次
 - 配金属银/金饰品打破沉闷
 - 全黑适合所有场合
 
 ## 4. 男性穿搭层次公式
 
 **基本3层**：T恤/衬衫 + 针织衫 + 外套
 
 ### 领口层次
 | 层数 | 领型 | 示例 |
 |------|------|------|
 | 第1层(内搭) | 圆领或V领T恤 | White T |
 | 第2层(中间) | 衬衫领或针织圆领 | 牛津衬衫 |
 | 第3层(外套) | 翻领或无领 | 牛仔夹克 |
 
 每层领型不同，领口露出1-2cm = 精致细节。
 
 ### 下摆层次
 T恤(最长) → 衬衫(中) → 外套(最短或最长)
 形成"阶梯感"，避免中间长度卡在臀部最宽处。
 
 ## 5. 男人单品质量排序
 
 ### 值得投资（买好的）
 1. **鞋**：每天穿，承受全身重量，好坏一眼看出
 2. **外套**：占全身50%面积，直接影响第一印象
 3. **包**：使用频率高，质感差异大
 4. **手表**：男人的唯一珠宝
 5. **牛仔裤**：好的牛仔能穿10年
 
 ### 可以省钱
 1. T恤（消耗品，勤换比贵更重要）
 2. 袜子（看不到，舒适即可）
 3. 帽子（随心情更换）
 4. 内搭（外露面积小）
 
 ## 6. 袖口与裤长细节（男人的魔鬼细节）
 
 ### 袖口
 - 衬衫袖口露出外套 **1-2cm** → 精致商务
 - 卷袖口：不超过 **2折**，卷到小臂中段
 - 卷法：窄而紧，不要松垮堆叠
 
 ### 裤长
 | 裤长类型 | 效果 | 适合 |
 |---------|------|------|
 | 不堆（刚好盖鞋面） | 经典利落 | 商务/休闲均可 |
 | 九分（露脚踝） | 最精神、显高 | 春夏休闲 |
 | 堆在鞋面（1-2折） | 慵懒随性 | 特定街头风格 |
 | 拖地（完全堆叠） | 大胆个性 | 潮流/时尚场合 |
 
 **建议**：不堆 > 九分 > 微堆 > 拖地
 
 ### 挽裤脚
 - 不超过2折
 - 折的宽度2-3cm
 - 露出脚踝最细处
 
 ## 7. 男性衣领选择
 
 | 脸型 | 最佳领型 |
 |------|---------|
 | 圆脸/方脸 | 尖角领（Point Collar）— 拉长脸部 |
 | 长脸 | 温莎领（Spread Collar）— 横向延展 |
 | 椭圆形 | 所有领型均可 |
 
 | 场合 | 最佳领型 |
 |------|---------|
 | 商务正式 | 温莎领（领带结大而饱满） |
 | 日常通勤 | 尖角领（百搭） |
 | 休闲 | 纽扣领（Button Down） |
 
 ## 8. 男性穿搭常见雷区
 
 | ❌ 不要 | ✅ 替代方案 |
 |---------|-----------|
 | 裤脚堆在鞋面（不挽不裁） | 九分裤或挽2折 |
 | 皮带和鞋颜色差很大 | 皮带≈鞋的颜色 |
 | 袜子太短露小腿 | 长袜到小腿中 |
 | T恤领口松垮变形 | 定期换新，领口挺括 |
 | 衣服皱巴巴不熨 | 衬衫/棉麻必须熨 |
 | 一身Logo | 无Logo更高级 |
 | 运动鞋配正装（非混搭风） | 乐福鞋/德比鞋 |
 | 短裤太长过膝 | 膝上3-5cm |
 | 裤子太紧（紧身牛/窄脚） | 直筒/Slim Straight |
 
 ## 9. 男性各季节穿搭要点
 
 ### 春夏
 - 颜色：浅色/中性色为主
 - 材质：棉、麻、薄针织
 - 层次：T恤+衬衫（当外套）/ 衬衫+薄夹克
 - 单鞋：帆布鞋/小白鞋/乐福鞋
 
 ### 秋冬
 - 颜色：深色/暖色为主（藏蓝/灰/大地/酒红/军绿）
 - 材质：羊毛/灯芯绒/牛仔/皮/羽绒
 - 层次：3层起步（内搭+中间+外套）
 - 围巾/帽子/手套 = 增加细节
 - 靴子：切尔西/沙漠/马丁
 
 ## 10. 男性快速穿搭公式（按分钟）
 
 ### 3分钟出门
 白T + 蓝直筒牛 + 白鞋
 
 ### 5分钟约会
 黑针织 + 灰西裤 + 切尔西靴
 
 ### 10分钟商务休闲
 白衬衫(不领带) + 卡其裤 + 深蓝Blazer + 乐福鞋
 
 ### 15分钟正式
 白衬衫 + 藏蓝西装 + 深蓝领带 + 牛津鞋
