 # 男性体型适配
 
 ## 男性四大体型诊断
 
 判断标准：观察肩宽 vs 腰宽 vs 胯宽的关系。
 
 ### 倒三角型 / V型 / T型
 
 **特征**：肩宽 > 胯宽，背部较厚，上半身呈倒三角
 
 **原则**：弱化肩部，强调腿部
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | V领/深圆领 — 打破肩部宽度感 | 横条纹 — 视觉加宽肩部 |
 | 直筒裤/微阔腿裤 — 平衡上下 | 垫肩/肩章 — 强化肩宽 |
 | 浅色下装 — 把注意力移到下半身 | 插肩袖/落肩不明显款式 |
 | 垂感面料 — 柔和肩部线条 | 窄脚裤 — 上下对比更极端 |
 | 上深下浅配色 | 过紧的上衣 — 凸显三角 |
 
 **代表人物参考**：Henry Cavill、Chris Hemsworth
 
 ### 矩形 / H型
 
 **特征**：肩约=腰约=胯，偏瘦高，无明显曲线
 
 **原则**：增加体积感，制造层次，避免单调
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 叠穿（T恤+衬衫+夹克） — 制造层次体积 | 单薄一层 — 显瘦弱 |
 | 格纹/横条纹/印花 — 增加宽度 | 全身紧身 — 暴露瘦削 |
 | Oversize/落肩款 — 增加体积 | 竖条纹 — 更显细长 |
 | 有厚度的面料 — 粗针织/厚牛仔 | 过于合身的西装 |
 | 肩部有设计 — 胸袋/肩章 | |
 | 宽松直筒裤 — 不强调细腿 | |
 
 **代表人物参考**：Timothée Chalamet、李现
 
 ### 椭圆型 / O型
 
 **特征**：腰围 > 肩宽，圆润，肚子突出
 
 **原则**：纵向拉长，避开腰线，不做横向分割
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 竖条纹/V领 — 纵向拉长 | 横条纹 — 横向加宽 |
 | 深色 — 收缩色 | 扎腰/塞衣角 — 凸显肚子 |
 | 直筒/微阔裤型 — 不强调腿部线条 | 紧身 — 暴露体型 |
 | 硬挺面料 — 牛仔/牛津布/西装料 | 亮色/浅色在腹部 |
 | 垂感外套（长大衣） — 纵向遮盖 | 腰部有装饰/腰带太显眼 |
 | 外套敞开穿 — V形纵向线条 | 短夹克 — 在腰线截断 |
 
 **代表人物参考**：John Goodman、Jack Black
 
 ### 三角型 / A型
 
 **特征**：胯 > 肩，下半身比上半身宽，亚洲男性常见
 
 **原则**：加强肩部，弱化胯部
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 垫肩/肩部设计 — 加宽肩部 | 窄肩/落肩设计 — 更显窄 |
 | 横条纹/格纹在上半身 | 横条纹/亮色在下半身 |
 | 上浅下深配色 | 紧身裤/窄脚裤 — 显胯 |
 | 肩部有装饰（胸袋/肩章） | 垂感太强的上衣 |
 | 直筒/微阔裤型 | 锥形裤（上宽下窄更显胯） |
 
 **代表人物参考**：很多偏梨形的普通男性
 
 ## 男性体型快速判断表
 
 | 观察点 | 倒三角(V) | 矩形(H) | 椭圆(O) | 三角(A) |
 |--------|----------|---------|---------|---------|
 | 肩 vs 胯 | 肩>胯 | 肩≈胯 | 肩<腰 | 肩<胯 |
 | 腰线 | 有(细) | 无 | 粗 | 有(细) |
 | 肉分布 | 上/背 | 均匀偏瘦 | 腹部 | 下/臀部 |
 | 最适合外套 | 直筒无垫肩 | 垫肩/有结构 | 长/垂感 | 垫肩/宽肩 |
 | 最适合裤型 | 直筒/阔腿 | 直筒/宽松 | 直筒 | 直筒/微阔 |
 | 禁忌 | 强调肩 | 全身紧 | 扎腰 | 紧身下装 |
 
 ## 男性身高与版型
 
 ### < 170cm
 - 腰线是命线（高腰/腰带/塞衣角）
 - 鞋裤同色延伸腿
 - 九分裤露脚踝
 - V领延长颈部
 - 上衣不要太长（盖过臀部=压个子）
 - 外套长度：刚好盖臀部或不长于胯下
 
 ### 170-180cm
 - 标准身高，几乎所有版型都适合
 - 重点在比例优化而非显高
 - 注意裤长别堆
 
 ### > 180cm
 - 可以驾驭更多单品（阔腿/长外套/长裙(？)）
 - Oversize显大气
 - 避免鞋跟太高
 - 注意比例——太高的人穿不好更显"竹竿"
 
 ## 男性体型-风格匹配
 
 | 体型 | 最适合风格 | 第二适合 |
 |------|-----------|---------|
 | 倒三角(V) | Classic/工装 | Clean Fit |
 | 矩形(H) | Clean Fit/学院 | 叠穿层次风 |
 | 椭圆(O) | 商务/极简/质感 | Ivy/Preppy |
 | 三角(A) | 工装/街头 | 军装/Vintage |
