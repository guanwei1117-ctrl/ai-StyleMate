 # 通用体型知识
 
 ## 1. 头肩比
 
 **理想肩宽 ≈ 2.5~3倍头宽**
 
 ### 肩太窄 (< 2.5倍头宽)
 | 解决方案 | 说明 |
 |---------|------|
 | 垫肩 | 西装/夹克选带垫肩款 |
 | 泡泡袖/羊腿袖 | 增加肩部体积 |
 | 肩章/肩部装饰 | Epaulet设计 |
 | 横条纹 | 视觉扩张肩部 |
 | V领/大领口 | 露肤让肩部显宽 |
 
 ### 肩太宽 (> 3倍头宽)
 | 解决方案 | 说明 |
 |---------|------|
 | V领/深U领 | 视觉上"切断"肩宽 |
 | 插肩袖/落肩款 | 不强调肩线 |
 | 深色上衣 | 收缩色 |
 | 垂感面料 | 柔和肩部线条 |
 | 避免：垫肩、泡泡袖、肩章、横条纹 |
 
 ## 2. 腰线位置
 
 **腰线决定视觉腿长，是最重要的比例调控点。**
 
 | 腰线位置 | 效果 | 适合人群 |
 |----------|------|---------|
 | 自然腰（肚脐） | 标准比例 | 所有人 |
 | 高腰（肚脐上2-5cm） | 显腿长10cm+ | 小个子/五五分 |
 | 帝国腰（胸下） | 显腿巨长 | 连衣裙/高腰款 |
 | 低腰（肚脐下） | 复古/个性（Y2K） | 腰短腿长的人 |
 
 **没有腰线 → 人工制造**：腰带、腰包、衣服打结、塞衣角、颜色分割
 
 ## 3. 头身比优化
 
 **东亚平均：6.5~7头身**
 
 **通过穿搭可优化至7~7.5头身视觉：**
 
 | 技巧 | 效果 |
 |------|------|
 | 鞋裤同色 | 视觉延伸腿部，+0.5头身 |
 | V领 | 延长颈部视觉 |
 | 高腰线 | 腿部视觉增加 |
 | 统一鞋裤颜色 | 腿部不被截断 |
 | 露脚背的鞋 | 增加腿长视觉 |
 | 竖线条纹/纵向缝线 | 拉长整体 |
 
 ## 4. ⚡横竖条纹视觉欺骗
 
 | 条纹方向 | 效果 | 适用 |
 |---------|------|------|
 | 竖条纹 | 显瘦、显高 | 需要拉长部位 |
 | 横条纹 | 显宽、显厚重 | 需要增加体积部位 |
 | 斜条纹 | 动感、修饰 | 不规则修饰 |
 
 **条纹搭配铁律**：
 - 不同方向条纹不叠穿（视觉混乱）
 - 竖条纹间距不要过密（会视觉眩晕）
 - 横条纹宽度与身形成正比（胖人选细横纹）
 
 ## 5. 身高与穿搭
 
 ### 小个子 (<160cm 女 / <170cm 男)
 | ✅ 做 | ❌ 不做 |
 |------|--------|
 | 高腰线（命线） | Oversize不控制比例 |
 | 鞋裤同色延伸腿 | 中长裙卡小腿肚 |
 | V领延长颈部 | 裤脚堆在鞋面 |
 | 裙长选膝上或踝上5cm | 过于复杂的叠穿 |
 | 竖线条纹 | 宽大横条纹 |
 | 高跟鞋/厚底（适度） | 过大的包包 |
 
 ### 高个子 (>175cm 女 / >185cm 男)
 | ✅ 做 | ❌ 不做 |
 |------|--------|
 | 阔腿裤/长裙（身高撑得起） | 过于合身显拘谨 |
 | 叠穿层次（丰富不单调） | 鞋跟过高（过度） |
 | 大图案/大印花 | 太小的配饰 |
 | 平底鞋/低跟鞋 | |
 
 ## 6. 体重视觉管理
 
 ### 显瘦穿搭法则（适用于任何体型）
 
 1. **深色收缩 + 浅色膨胀**：深色在你想显瘦的部位，浅色在你想突出的部位
 2. **纵向线条**：竖条纹/纵向拉链/长项链 → 拉长视觉
 3. **露最瘦处**：锁骨/手腕/脚踝 → 让人聚焦你的优势
 4. **腰线即生命**：无论胖瘦，明确的腰线都显瘦
 5. **垂感面料**：雪纺/真丝/细针织 → 顺着身体垂下去，不显胖
 6. **挺括面料**：牛仔/西装料 → 有型有轮廓，不贴身
 7. **避免**：太贴身的弹力面料、横条纹在胖的部位、腰部有装饰
 
 ### 显壮穿搭法则（偏瘦人群）
 1. **叠穿**：增加体积感
 2. **横条纹/大格纹/印花**：视觉扩张
 3. **Oversize/落肩款**：不强调骨架
 4. **厚实面料**：粗针织/毛呢/廓形外套
 5. **浅色/暖色**：膨胀色
 
 ## 7. 身体部位修饰速查
 
 | 修饰目标 | 方法 |
 |---------|------|
 | 脖子短 | V领/U领/大圆领，❌高领/项链太紧 |
 | 脖子长 | 高领/项链/围巾/翻领 |
 | 手臂粗 | 蝙蝠袖/泡泡袖/落肩，❌无袖/紧身袖 |
 | 胸大 | V领/深色/垂感面料，❌高领/胸前大印花 |
 | 胸小 | 叠穿/胸前口袋/荷叶边/横条纹 |
 | 腰粗 | 垂感/A字/高腰但宽松，❌紧身/腰部装饰/低腰 |
 | 腰细 | 强调！（腰带/收腰/露腰） |
 | 胯宽 | A字裙/阔腿裤/长上衣遮，❌紧身包臀/浅色/大口袋 |
 | 大腿粗 | 直筒裤/阔腿裤/A字裙/长上衣，❌紧身裤/超短裙 |
 | 小腿粗 | 微喇裤/长裙/及踝靴，❌中长裙卡小腿肚 |
 | 脚踝粗 | 九分裤+靴子/长裤盖脚面，❌七分裤/细带凉鞋 |
 | 背厚 | 深色/V领，❌露背/横条纹/紧身 |
 | 小肚子 | 垂感/挺括面料/高腰A字，❌弹性紧身/亮面 |
