 # 颜色搭配法则
 
 ## 1. 色轮基础关系
 
 | 搭配类型 | 定义 | 效果 | 示例 | 难度 |
 |---------|------|------|------|------|
 | 同色系 | 同一色系不同深浅 | 最安全、高级、显高显瘦 | 深蓝衬衫+浅蓝牛仔裤 | ⭐ |
 | 邻近色 | 色轮相邻(30°-60°) | 柔和协调、有层次不张扬 | 蓝+紫、黄+橙、绿+蓝 | ⭐⭐ |
 | 对比色 | 色轮相对(120°-180°) | 大胆吸睛、有冲击力 | 蓝+橙(8:2配比)、红+绿 | ⭐⭐⭐ |
 | 互补色 | 色轮180°正对 | 最高对比、最吸睛 | 黄+紫(小面积点缀) | ⭐⭐⭐⭐ |
 | 三角色 | 色轮120°等距 | 丰富但不混乱 | 红+黄+蓝(主辅点1:1:1) | ⭐⭐⭐⭐ |
 
 ## 2. 中性色系统（穿搭安全区）
 
 ### 核心中性色
 黑、白、灰、卡其、军绿、藏蓝、驼色、米色、燕麦色、牛仔蓝
 
 ### 中性色法则
 - 中性色占全身 **60%以上** → 自动获得高级感
 - 任何鲜艳色 + 中性色 → 永远不会出错的组合
 - 中性色之间任意搭配 → 极简高级感
 
 ### 中性色搭配矩阵
 
 | 中性色A | 中性色B | 效果 |
 |---------|---------|------|
 | 白 | 卡其 | 清爽休闲 |
 | 黑 | 白 | 经典永恒 |
 | 藏蓝 | 卡其 | 商务休闲标杆 |
 | 灰 | 白 | 清冷高级 |
 | 驼色 | 白 | 温柔知性 |
 | 军绿 | 黑 | 硬朗户外 |
 | 米色 | 燕麦 | 暖调极简 |
 
 ## 3. 三色原则（60-30-10法则）
 
 - **主色60%**：外套/上衣/裤子（大面积）
 - **辅助色30%**：内搭/下装（次要面积）
 - **点缀色10%**：配饰/鞋/包/丝巾（亮点）
 
 示例：
 - 主色 = 藏蓝大衣(60%)
 - 辅助 = 米色针织(30%)
 - 点缀 = 红色围巾(10%)
 
 ## 4. 肤色适配
 
 ### 冷白皮
 | ✅ 适合 | ❌ 避开 |
 |---------|---------|
 | 蓝色系、紫色系、粉色系 | 橙/黄/荧光 |
 | 灰色系、正红、宝蓝 | 土黄/橄榄 |
 | 薄荷绿、薰衣草紫 | |
 
 ### 暖黄皮（亚洲人多见此）
 | ✅ 适合 | ❌ 避开 |
 |---------|---------|
 | 米色、驼色、奶白 | 荧光色(死亡芭比粉) |
 | 橄榄绿、酒红、深蓝 | 亮紫色、亮橙色 |
 | 豆沙粉、雾霾蓝 | 纯白(偏冷白更合适) |
 | 咖啡色、棕红色 | |
 
 ### 小麦皮/深肤色
 | ✅ 适合 | ❌ 避开 |
 |---------|---------|
 | 白色(高对比很好看) | 土黄(肤色融为一体) |
 | 宝蓝、正红、明黄 | 浑浊色(显脏) |
 | 大地色(同色系好看) | |
 
 ## 5. 进阶配色技巧
 
 - **鞋包同色**：鞋子和包包同色系，形成上下呼应，增加整体感
 - **内搭亮色法**：外套中性色 + 内搭鲜艳色，只露领口/袖口一点就够
 - **帽子呼应法**：帽子颜色呼应鞋子或包包，三角闭合
 - **白色隔离法**：两个难搭的颜色之间用白色过渡（如 红+白+绿 比 红+绿 更好）
 - **袜子点睛法**：袜子颜色呼应上衣或配饰，细节处见功夫
 - **金属色统一**：金色饰品配暖色/银色饰品配冷色，不混搭
 - **全身不超过3色**：包含鞋包，但不含金属配饰和印花中的次要色
 - **印花遵循底色**：印花的穿搭以印花中的主色为搭配依据
 
 ## 6. 季节推荐配色
 
 | 季节 | 推荐色系 | 搭配建议 |
 |------|---------|---------|
 | 春 | 柔和粉彩 | 薄荷绿+奶白 / 淡粉+灰 / 鹅黄+米 |
 | 夏 | 清爽冷调 | 天蓝+白 / 灰蓝+米 / 白+海军蓝 |
 | 秋 | 暖调大地 | 驼+橄榄+锈红 / 卡其+棕+酒红 |
 | 冬 | 高对比/深色 | 黑+白+正红 / 深蓝+灰+驼 |
 
 ## 7. 颜色心理学（印象管理）
 
 | 颜色 | 给人的印象 | 适合场合 |
 |------|-----------|---------|
 | 黑色 | 权威、神秘、显瘦 | 正式/商务/晚宴 |
 | 白色 | 洁净、简约、清新 | 约会/面试/春夏 |
 | 藏蓝 | 可靠、专业、稳重 | 商务/面试/通勤 |
 | 灰色 | 中庸、高级、低调 | 商务休闲/日常 |
 | 红色 | 自信、热情、吸睛 | 约会/派对/重要会议 |
 | 驼色 | 温柔、知性、质感 | 秋冬/通勤/约会 |
 | 绿色 | 自然、平衡、治愈 | 户外/日常 |
 | 粉色 | 柔和、女性化、亲和 | 约会/社交 |
 | 紫色 | 创意、神秘、奢华 | 创意场合/派对 |
