 # 材质搭配法则
 
 ## 1. 软硬对比法则（最重要）
 
 硬挺材质 + 柔软材质 = 层次感最佳。
 
 | 硬挺材质 | 柔软材质 | 搭配效果 |
 |---------|---------|---------|
 | 牛仔外套 | 丝质连衣裙 | 娘man平衡经典 |
 | 羊毛大衣 | 针织内搭 | 秋冬高级感 |
 | 皮夹克 | 雪纺裙/丝质上衣 | 摇滚+柔美 |
 | 西装外套 | 棉质T恤 | 商务休闲标杆 |
 | 工装夹克 | 针织毛衣 | 户外+温暖 |
 
 **禁忌**：
 - ❌ 全硬 = 僵硬/刻板（牛仔+皮+硬挺衬衫）
 - ❌ 全软 = 邋遢/没精神（针织+丝质+棉麻）
 
 ## 2. 厚薄搭配原则
 
 **上厚下薄 / 下厚上薄 = 有节奏感**
 
 | ✅ 推荐 | ❌ 避免 |
 |---------|---------|
 | 厚毛衣 + 薄纱裙 | 上下同厚 = 沉闷 |
 | 轻薄衬衫 + 厚呢裤 | 上下同薄 = 无层次 |
 | 厚外套 + 薄内搭 | |
 
 **冬季进阶**：内搭越薄越好（羊绒＞毛衣厚），外面才不臃肿
 
 ## 3. 光泽度控制
 
 **光泽度等级（从哑光到高光）**：
 棉麻(全哑) → 羊毛(微光) → 棉(自然) → 丝绸(柔光) → 缎面(中光) → 皮革(高光) → 亮片(超高)
 
 ### 光泽搭配规则
 - **全哑光** = 低调安全（日常首选）
 - **1个光泽单品 + 全哑光** = 恰到好处的亮点
 - **2个以上光泽单品** = 容易廉价/过于隆重
 - **相邻光泽度** 可搭配（丝绸+缎面OK）
 - **跨级光泽度** 需要中间过渡
 
 ### 推荐光泽单品
 丝质衬衫、缎面裙、皮质单品、珍珠饰品、金属配饰
 
 ## 4. 材质混搭指南
 
 | 搭配组合 | 效果 | 适合风格 |
 |---------|------|---------|
 | 牛仔 + 针织 | 休闲舒适 | 日常/通勤 |
 | 皮质 + 针织 | 硬朗+柔软的反差 | 街头/个性 |
 | 丝质 + 粗花呢 | 优雅碰撞 | 约会/派对 |
 | 棉麻 + 西装料 | 松弛高级感 | 通勤/商务休闲 |
 | 蕾丝 + 牛仔 | 娘man平衡 | 约会/周末 |
 | 针织 + 西装料 | 通勤首选 | 通勤/商务休闲 |
 | 皮革 + 丝绸 | 奢华硬朗 | 派对/晚宴 |
 | 卫衣棉 + 西装料 | 运动+正式 | Urban/混搭 |
 | 粗针织 + 缎面 | 温暖+柔滑 | 秋冬约会 |
 
 ## 5. 材质与体型关系
 
 | 材质类型 | 效果 | 适合体型 |
 |---------|------|---------|
 | 挺括（牛仔/西装料） | 有骨骼感，修饰形状 | 偏胖/圆润身材 |
 | 垂感（真丝/雪纺/细针织） | 纵向拉长，柔和线条 | 所有体型，尤其偏胖 |
 | 蓬松（羽绒/粗针织） | 增加体积感 | 偏瘦身材 |
 | 弹力（莱卡/弹力棉） | 贴身显形 | 标准/偏瘦身材 |
 | 硬挺（皮/厚牛仔/帆布） | 廓形感 | 偏瘦/标准身材 |
 | 柔软（棉/薄针织/丝） | 贴身柔和 | 偏瘦/标准身材 |
 
 ## 6. 材质避雷指南
 
 ### 廉价感材质（谨慎使用）
 - 低密度化纤（塑料袋感）
 - 起球严重的混纺
 - 透光性差的白色涤纶
 - 闪亮的塑料感PU皮
 
 ### 高级感材质（推荐投资）
 - 100%羊毛/羊绒
 - 真丝（Silk）
 - 高品质棉（长绒棉/埃及棉）
 - 纯亚麻（Linen）
 - 真皮（Leather）
 
 ## 7. 面料组合速查
 
 | 想达到的效果 | 推荐组合 |
 |------------|---------|
 | 高级感 | 羊绒+真丝+羊毛 |
 | 休闲舒适 | 棉+牛仔+针织 |
 | 正式商务 | 羊毛+棉+丝绸 |
 | 约会浪漫 | 丝绸+蕾丝+针织 |
 | 街头个性 | 牛仔+皮+卫衣棉 |
 | 秋冬温暖 | 羊绒+羊毛+羽绒 |
 | 春夏清爽 | 亚麻+棉+真丝 |
