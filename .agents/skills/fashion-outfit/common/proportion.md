 # 比例与视觉技巧
 
 ## 1. 上短下长（黄金比例法则）
 
 ### 原理
 通过提高腰线视觉位置，让腿看起来更长，优化头身比。
 
 ### 操作方法
 - 上衣下摆塞进裤子/裙子（Full Tuck / French Tuck）
 - 高腰裤/高腰裙 + 短款上衣（Crop Top / 短针织）
 - 腰带在最细的腰部位置系紧
 - 上衣打结（T-shirt Knot）人工制造腰线
 
 ### 适用人群
 - ✅ 小个子（<165cm 女性 / <175cm 男性）
 - ✅ 五五分身材
 - ✅ H型身材（需要制造腰线）
 
 ### 慎用人群
 - ⚠️ 腰特别长的人（过度强调会显得上身更短）
 - ⚠️ 非常高的个子（180cm+ 不需要刻意拉腿）
 
 ## 2. 上宽下窄（平衡法则）
 
 ### 原理
 上身宽松 + 下身修身 = 倒三角稳定视觉 + 显瘦。
 
 ### 操作方法
 - Oversize卫衣/衬衫 + 修身裤/窄脚裤/紧身裙
 - 宽肩外套 + 直筒裤/烟管裤
 - 落肩T恤 + 紧身牛仔裤
 
 ### 适用人群
 - ✅ 肩宽胯窄（倒三角/草莓型）— 平衡上下比例
 - ✅ 上半身偏胖（用宽松遮盖，用修身裤显下半身纤细）
 - ✅ 梨形上半身（上身宽松+下身深色窄脚）
 
 ### 慎用人群
 - ⚠️ 下半身已经非常纤细的人（会显头重脚轻）
 - ⚠️ 胯宽的人（上宽下窄会让胯部更突兀→此时适合上窄下宽）
 
 ## 3. 上窄下宽（优雅法则）
 
 ### 原理
 上身修身 + 下身宽松 = X型沙漏轮廓 + 女性化线条。
 
 ### 操作方法
 - 修身针织/紧身T恤 + A字裙/阔腿裤/伞裙
 - 贴身内搭 + 百褶裙/蓬蓬裙
 - V领修身 + 喇叭裤
 
 ### 适用人群
 - ✅ 梨形身材 — 修身上衣突出上半身优势，阔腿裤遮胯
 - ✅ 苹果型身材 — 修身显上半身线条，宽松裤舒适不勒腰
 - ✅ 窄肩人群 — 上身修身不会让肩部显宽
 
 ### 慎用人群
 - ⚠️ 肩宽+胯窄（上窄下宽会加剧倒三角的不平衡）
 
 ## 4. 3:7 黄金分割
 
 ### 原理
 上装视觉占比3 : 下装视觉占比7，最接近人体黄金分割比(1:1.618)。
 
 ### 实现方式
 - 高腰单品（裤腰在肚脐以上2-3cm）
 - 塞衣角 + 腰带强调
 - 同色系上下延伸（鞋裤同色 → 视觉腿更长）
 - 外套敞开穿，露出内搭的高腰线
 
 ## 5. 1:1 禁区（五五分警戒）
 
 ### 问题
 上衣下装各占50%，视觉上腿短、比例呆板。
 
 ### 常见情况
 - 普通T恤+中腰裤不塞
 - 中长外套（盖过臀部） + 中长裙
 - 腰线模糊的连衣裙
 
 ### 破解方案
 - ✅ 塞衣角（制造高腰线）
 - ✅ 加腰带（人工分割3:7）
 - ✅ 露腰（Crop Top 直接打破1:1）
 - ✅ 颜色分割（上下不同色但上短下长）
 - ✅ 外套长度控制（要么短夹克<臀部，要么长大衣>膝盖，别卡在臀部）
 
 ## 6. 叠穿层次法则
 
 ### 三层原则
 内搭 → 中间层 → 外套，每层长度不同形成阶梯感。
 
 | 层次 | 功能 | 长度原则 |
 |------|------|---------|
 | 内搭(1层) | 贴肤 | 最长或中等 |
 | 中间层(2层) | 保暖 | 最短（避免卡在最尴尬位置） |
 | 外套(3层) | 轮廓 | 最长或与内搭等长 |
 
 ### 领口层次
 每层领型不同：圆领内搭 + V领中间层 + 翻领外套
 领口露出内搭1-2cm → 精致细节
 
 ## 7. 视觉重心控制
 
 | 重心位置 | 方法 | 效果 |
 |---------|------|------|
 | 重心在上 | 亮色上衣/吸睛项链/围巾/帽子 | 显高、聚焦面部 |
 | 重心在下 | 亮色鞋/图案下装/彩色袜子 | 个性、分散注意力 |
 | 重心居中 | 腰带/腰链/腰包 | 强调腰线、显比例 |
 
 **建议**：小个子/圆脸 → 重心在上；高个子/长脸 → 可上可下
 
 ## 8. 露肤法则
 
 ### 核心
 露哪里就强调哪里，全身最多露1-2处。
 
 ### 最佳露肤点（按安全度排序）
 | 露肤点 | 安全度 | 效果 |
 |--------|--------|------|
 | 脚踝 | ⭐⭐⭐⭐⭐ | 最安全，显高不张扬 |
 | 手腕 | ⭐⭐⭐⭐⭐ | 自然随意 |
 | 锁骨 | ⭐⭐⭐⭐ | 优雅性感 |
 | 颈部(V领) | ⭐⭐⭐⭐ | 延长颈线 |
 | 腰部(露腰) | ⭐⭐⭐ | 年轻活力 |
 | 肩部(一字领) | ⭐⭐⭐ | 女性化 |
 | 背部 | ⭐⭐ | 性感但挑人 |
 | 腿部(短裙) | ⭐⭐ | 场合受限 |
 
 ### 露肤组合规则
 - ✅ 领口 + 手腕（最佳组合）
 - ✅ 领口 + 脚踝（优雅）
 - ✅ 腰 + 手腕（年轻）
 - ❌ 领口 + 腰 + 腿 = 露太多
 - ❌ 同时露胸和腿 = 性感过度
 - ❌ 同时露背和腰 = 过于暴露
 
 ## 9. 领型与脸型
 
 | 脸型 | 最佳领型 | 避开领型 |
 |------|---------|---------|
 | 圆脸 | V领、深U领（纵向拉长） | 圆领、高领、彼得潘领 |
 | 方脸 | V领、U领、荡领（柔和棱角） | 方领、一字领 |
 | 长脸 | 圆领、高领、翻领（横向截断） | 深V领 |
 | 心形脸 | 圆领、船型领、小立领 | 深V（会强化尖下巴） |
 | 椭圆脸 | 所有领型 | 无限制 |
 
 ## 10. 图案与印花搭配
 
 - **全身一个重点**：一条格纹裤 + 纯色上衣，不要上下都花
 - **条纹不叠条纹**：不同方向的条纹不穿在一起
 - **大花配纯色**：大面积印花配纯色单品
 - **图案呼应**：上衣的图案颜色 = 下装的纯色
 - **动物纹小面积**：豹纹/斑马纹作为配饰或局部使用
 - **格纹规则**：不同格纹不混搭（除非是复古风特意为之）
