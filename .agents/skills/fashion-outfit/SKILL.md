 ## 🧠 核心原则
 
 ### 三重决策机制（详见 decision.md）
 
 **最终穿搭建议 = AI分析(40%) + Skill规则(40%) + 用户记忆(20%)**
 
 - **AI分析(40%)**：基于上传图片进行体型/肤色/气质分析，结合时尚审美给出创意方案
 - **Skill规则(40%)**：本技能收录的穿搭规则库，确保建议专业规范
 - **用户记忆(20%)**：该用户的个人偏好、避雷清单、历史好评，做最终权衡
 
 ### 关键约束
 
 1. **Skill ≠ 记忆**：Skill是全局规则池（适用于所有用户），记忆是用户个人数据，两者互不干扰
 2. **Rule-Aware, Not Rule-Bound**：Skill是参考框架而非铁律，AI可根据具体场景合理突破规则并给出解释
 3. **记忆优先在风格选择**：整体建议中记忆占20%，但在多方案最终选择时，用户避雷项拥有一票否决权
 4. **标注来源**：每条建议必须标注依据来源（AI / Skill规则 / 用户记忆）
 
 ## 🔄 工作流程
 
 当用户上传图片或描述需求时，按以下流程执行：
 
 ```
 Step 1: 信息提取
   ├── 从图片分析：体型、肤色、发色、现有穿搭、气质风格、性别
   ├── 从用户描述：场合需求、风格偏好、预算范围
   └── 从用户记忆（若有）：历史偏好、满意/不满意记录、避雷清单
 
 Step 2: 规则匹配 (40%)
   ├── 根据性别加载 male/ 或 female/ 规则集
   ├── 匹配体型规则 → 推荐修饰体型的穿法
   ├── 匹配颜色规则 → 推荐配色方案
   ├── 匹配风格规则 → 推荐风格组合
   ├── 匹配场合规则 → 确保得体
   ├── 匹配材质规则 → 优化质感
   └── 匹配比例规则 → 优化视觉分割
 
 Step 3: AI创意分析 (40%)
   ├── 基于时尚审美 + 当前流行趋势
   ├── 结合图片实际条件灵活调整
   ├── 可突破规则但必须有合理时尚依据
   └── 考虑季节性、地域性等因素
 
 Step 4: 用户记忆调优 (20%)
   ├── 读取用户历史偏好（风格/颜色/品牌/版型偏好）
   ├── 读取用户避雷清单（明确不喜欢的元素→直接排除）
   ├── 读取历史好评搭配（优先推荐相似方案）
   └── 最终选择时，记忆有"一票否决权"
 
 Step 5: 方案整合与输出
   ├── AI方案 + Skill方案 交叉验证，取交集优化
   ├── 用户记忆做最终过滤和微调
   ├── 输出2-3个方案供选择
   └── 每条建议标注来源：(🤖AI) / (📐Skill) / (👤记忆)
 ```

 ## 🎬 用户使用方式
 
 用户可通过以下方式使用本技能：
 1. **上传照片** → AI分析当前穿搭并给出改进建议
 2. **描述身材特征** → 根据体型推荐穿搭公式
 3. **说明场合需求** → 推荐得体搭配
 4. **描述风格偏好** → 推荐风格组合
 5. **询问具体单品搭配** → 提供搭配方案
 6. **衣橱整理** → 基于用户现有单品做搭配
 
 ## ⚠️ 重要限制
 
 - 禁止AI仅凭自身知识给出穿搭建议而不引用Skill规则
 - 禁止Skill规则完全取代AI的创意判断（Rule-Aware, Not Rule-Bound）
 - 禁止将用户记忆与Skill规则混淆
 - 禁止忽略场合因素（场合优先级最高）
